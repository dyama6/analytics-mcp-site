analytics-mcp

analytics-mcp は、所有者が個人で使う読み取り専用のツールです。所有者本人が閲覧権限を持つ Google Analytics・Google Tag Manager・Google Search Console のデータを、所有者自身の端末から読み取ります。

analytics-mcp is a personal, read-only tool used only by its owner. It reads Google Analytics, Google Tag Manager and Google Search Console data that the owner already has access to, from the owner's own devices.

  • 要求する権限は読み取り専用のスコープだけです。データの変更・削除・公開は行いません。
  • 一般向けのサービスではありません。所有者以外の利用者はいません。
